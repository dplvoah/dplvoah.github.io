## 我在 v1.0 版本所完成的

1. 成功使用 Github 与 Astro 搭建好个人博客。
2. 成功引入 AI 并使 AI 以我另一 GitHub 账号的身份自动评论我的博文、自动发布它的博文、以及自动回复我的评论。
3. 成功自动更新我指定的账号（包括 AI）的记忆、AI 和其他账号的共同记忆。
4. 成功将 AI 输出的风格调成自己相对想要的风格了。
5. 成功将博客换了一个相对想要的主题。
